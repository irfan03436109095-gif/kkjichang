在线工具：IP 查询与 Ping 测试

01 / 公网信息

IP 查询

查看公网 IP 的归属地区、网络与运营商信息，也可查询当前出口。

支持公网 IPv4、IPv6。留空可查询当前公网出口。

输入 IP 地址，或选择查询当前公网出口。

查询会将地址发送至 ipwho.is，服务不可用时使用 IP.sb。查询我的 IP 时，服务将识别本次连接的公网出口；IP 归属地为近似信息。

02 / 远程连通性

Ping 测试

从远程网络探针发起 ICMP Ping，查看目标的响应时间与丢包情况。

只填写域名或 IP，不含协议、路径和端口。

选择目标和区域后开始测试。

测试由 Globalping 远程探针发起，反映探针到目标的网络情况，与访客本机延迟不同。目标会提交至 Globalping，测试结果可能公开。停止等待不会撤回已提交的测试。

输入公网 IP 查询网络归属，或使用远程探针检查目标连通性。所有查询均在你点击按钮后发起，结果直接显示在上方工具中。

IP 查询结果怎么看

“查询我的 IP”显示查询服务观察到的公网出口，可能是路由器、运营商、代理或 VPN 的出口，并非设备的内网地址。指定地址查询支持公网 IPv4 和 IPv6。

国家、地区、城市、ISP 和 ASN 来自 IP 数据库，可能存在更新延迟或定位误差，不能作为某个人或设备的精确位置证据。

Ping 测试结果怎么看

本页使用 Globalping 的公共网络探针发出真实 ICMP Ping，每次最多选择 3 个探针，每个探针发送 3 个包。可以选择全球、亚洲、欧洲或北美洲探针。

平均、最小和最大延迟以毫秒计，丢包率以百分比计。结果显示探针所在城市、国家和网络，以及目标解析地址；数值缺失时显示“—”，不会把失败当成零延迟。

测试路径是“远程探针 → 目标”，不能代表你自己的设备到目标的延迟。目标禁用或限制 ICMP 时可能无响应，不能仅凭这一项断定网站不可访问。

查询服务与数据

IP 查询会将查询地址发送给 ipwho.is；主服务不可用时，使用 IP.sb 作为备用来源。查询当前出口时，该服务将看到本次请求的公网地址。Ping 会将目标提交至 Globalping，测量数据可能公开。请勿输入私人订阅、带密码的链接或内部系统地址。

“停止等待”只停止本页继续读取结果，已提交的远程测量可能继续完成。接口可能受网络、浏览器策略或服务配额限制；失败时页面会显示原因，可以稍后重试。
