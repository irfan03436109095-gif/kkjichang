机场写“多设备”就能同时用吗？把设备数和在线 IP 分开试

“支持多设备”可能指允许导入的设备数量，也可能另有限制同时连接数或在线公网 IP 数。买前把服务方原文截图和日期留好，逐条问清：“能装几台、能同时用几台、是否限制同时在线 IP、触发后怎样恢复”。不要仅凭一句“可以共享”就推断全部条件。

为什么两台设备不一定等于两个公网 IP

RFC 3022 描述的 NAPT 可让多个内网设备共享一个外部地址。家庭 Wi-Fi 下的电脑和手机可能共享接入侧公网 IP；手机切到蜂窝后，来源地址可能不同。但机场实际统计的是账号、连接、入口 IP 还是其他口径，必须以其条款和试用反馈为准。

两组场景做小任务验收

  1. 先只用电脑连接一个节点，完成登录与网页访问，记下后台可见的设备或会话信息。
  2. 保持电脑在线，让手机同连家庭 Wi-Fi，登录同一服务并做小任务。记录第二台是否可用、第一台是否被挤下线。
  3. 若条款允许，再让手机切到蜂窝，重复同一任务。每次只变网络，记录时间、错误提示和是否需要重新登录。不要公开完整 IP、订阅 URL 或账号截图。

示意图：设备数量、并发会话和公网 IP 数量要分开记录。

怎样作购买决定

三次都通过，只能说明当前账号、时段和节点组合可用；还要问清正式套餐与试用是否同规则。若“同 Wi-Fi 可用、蜂窝不行”，可能涉及在线 IP 限制；若两处都不行，也可能是并发数或账号权限。先请服务方按条款解释，不把一次失败直接写成全站故障。
